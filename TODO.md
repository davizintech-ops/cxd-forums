# Entregas

## Reformulação mobile-first e responsiva
- [x] A interface deve priorizar celular, adaptar-se a telas maiores e manter navegação acessível por toque.
- [x] O projeto deve ficar mais bonito, mais lógico e com acabamento visual consistente.
- [x] A experiência deve usar animações de scroll/entrada suaves, sem sacrificar leveza em celulares.

## Funcionalidade do fórum
- [x] Manter criação de tópico, listagem de tópicos, abertura de tópico e respostas.
- [x] Corrigir carregamento da página de populares e referência quebrada ao renderizar respostas.
- [x] Manter autenticação, cadastro, perfil, configurações e administração compatíveis com o Supabase existente.

## Qualidade de entrega
- [x] Manter arquitetura sem dependências pesadas e com fallback para redução de movimento.
- [ ] Validar as páginas em servidor local e corrigir erros de sintaxe/recursos ausentes.
